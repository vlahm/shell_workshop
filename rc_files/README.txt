There are 3 dotfiles in this folder, so they'll be hidden in some contexts. The 4 files are:

.zshrc			(macos)
.bashrc			(Git Bash)
.bashrc_linux	(Linux; this needs to be renamed to .bashrc before it will work)
rc_generic		(should work anywhere. limited commands)

shell-rc-setup.txt contains instructions for using these files
